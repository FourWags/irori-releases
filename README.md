# Irori Preview releases

This is Irori's public APK release channel for Obtainium. The application source repository is maintained separately.

Add this repository URL to Obtainium: **https://github.com/FourWags/irori-releases**.

Download the latest **petal-reader-epub.apk** from [Releases](https://github.com/FourWags/irori-releases/releases/latest). Each release includes checksums, test scope and third-party notices. The stable Android package is `dev.fourwags.petalreader`; preserve the signing identity when updating.

Irori reads local EPUB books and has optional network features. Preview/Latest status does not establish production or store readiness. Read each release's limits. Existing physical-device updates should go through Obtainium.

Application/Liseur copyright and MIT license are retained in `LICENSE.txt` with each release. Readium and other runtime components and fonts retain their individual licenses in `THIRD-PARTY-NOTICES.zip`. This repository's automatic source archives contain release-channel documentation only.
